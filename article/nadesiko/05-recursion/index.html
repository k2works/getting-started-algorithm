    第 5 章 再帰アルゴリズム¶

    はじめに¶

    再帰とは、関数が自分自身を呼び出して問題を解く方法です。大きな問題を同じ形の小さな問題に分け、答えがすぐに求まるところまで進んでから、呼び出し元へ結果を返します。

    再帰関数には、呼び出しを止める 基底条件 と、問題を小さくして再び関数を呼び出す 再帰ステップ が必要です。基底条件がなかったり、再帰ステップで問題が小さくならなかったりすると、処理が終わりません。この章では、階乗、ユークリッドの互除法、ハノイの塔に加え、複数回再帰の反復化、8 王妃問題、迷路探索を実装します。

    5.1 階乗¶

    非負整数 n の階乗は、n から 1 までの整数を掛け合わせた値です。0! は 1 と定義され、n! = n × (n - 1)! の関係を使うと再帰で表せます。この関数は非負整数を入力とする前提です。

    Red: 基底条件と再帰結果をテストする¶

    「階乗: 0の基底条件」と(0で階乗)と1で検証
「階乗: 1」と(1で階乗)と1で検証
「階乗: 5」と(5で階乗)と120で検証

    Green: 問題を 1 つ小さくする¶

    ●(数で)階乗
    もし、数 <= 1ならば
        1を戻す
    ここまで
    (数 × ((数 - 1)で階乗))を戻す
ここまで

    階乗(5) は 5 × 階乗(4) を求め、さらに 4 × 階乗(3) と続きます。階乗(0) に到達すると基底条件の 1 を返し、呼び出し元で順に乗算されます。

    階乗(5)
= 5 × 階乗(4)
= 5 × 4 × 階乗(3)
= 5 × 4 × 3 × 階乗(2)
= 5 × 4 × 3 × 2 × 階乗(1)
= 5 × 4 × 3 × 2 × 1
= 120

    n 回程度の関数呼び出しを行うため、時間計算量は O(n)、再帰呼び出しを保持する空間計算量も O(n) です。n が大きすぎると、処理系の再帰上限や利用可能なスタック容量に達する場合があります。

    5.2 最大公約数 — ユークリッドの互除法¶

    ユークリッドの互除法は、2 つの非負整数 x、y の最大公約数について、gcd(x, y) = gcd(y, x % y) が成り立つことを利用します。余りが 0 になったときの x が最大公約数です。

    Red: 基底条件と余りをテストする¶

    「最大公約数: 互除法」と(22と8で最大公約数)と2で検証
「最大公約数: 互いに素」と(7と11で最大公約数)と1で検証
「最大公約数: 余りが0」と(18と6で最大公約数)と6で検証

    Green: 余りを次の問題にする¶

    ●(XとYで)最大公約数
    もし、Y = 0ならば
        Xを戻す
    ここまで
    (Yと(X % Y)で最大公約数)を戻す
ここまで

    例えば 最大公約数(22, 8) は、最大公約数(8, 6)、最大公約数(6, 2)、最大公約数(2, 0) と問題が小さくなり、2 を返します。余りは必ず小さくなるので、Y = 0 の基底条件に到達します。

    ユークリッドの互除法の時間計算量は O(log min(x, y)) です。再帰呼び出しの空間計算量も O(log min(x, y)) になります。引数は非負整数を前提とします。

    5.3 ハノイの塔¶

    ハノイの塔では、大小の異なる円盤を 3 本の柱の間で移動します。大きな円盤を小さな円盤の上に置かず、1 回に 1 枚だけ動かします。n 枚を移動元から移動先へ移すには、次の 3 段階に分けます。

    1. 上の n - 1 枚を移動元から経由先へ移す。
    2. 残った一番大きな円盤を移動元から移動先へ移す。
    3. n - 1 枚を経由先から移動先へ移す。

    Red: 移動手順と基底条件をテストする¶

    移動手順は [移動元, 移動先] の配列の一覧として返します。1 枚なら移動は 1 回、3 枚なら 2³ - 1 = 7 回です。0 枚なら移動はありません。

    移動一覧 = 1と「A」と「C」と「B」でハノイ解法
「ハノイ: 1枚の移動数」と(移動一覧の配列要素数)と1で検証
移動 = 移動一覧の0を配列参照
「ハノイ: 1枚の移動元」と(移動の0を配列参照)と「A」で検証
「ハノイ: 1枚の移動先」と(移動の1を配列参照)と「C」で検証

移動一覧 = 3と「A」と「C」と「B」でハノイ解法
「ハノイ: 3枚の移動数」と(移動一覧の配列要素数)と7で検証
移動 = 移動一覧の0を配列参照
「ハノイ: 最初の移動」と(移動を「-」で配列結合)と「A-C」で検証
移動 = 移動一覧の3を配列参照
「ハノイ: 最大円盤の移動」と(移動を「-」で配列結合)と「A-C」で検証

移動一覧 = 0と「A」と「C」と「B」でハノイ解法
「ハノイ: 0枚なら移動しない」と(移動一覧の配列要素数)と0で検証

    Green: 移動手順を配列に記録する¶

    再帰の途中で作った移動手順をひとつの配列に集めるため、配列を再帰関数に渡します。なでしこ3 の配列は参照型なので、各呼び出しが同じ配列に移動を追加します。

    ●(枚数と移動元と移動先と経由と移動一覧で)ハノイ移動記録
    もし、枚数 <= 0ならば
        移動一覧を戻す
    ここまで
    もし、枚数 = 1ならば
        移動一覧に[移動元, 移動先]を配列追加
        移動一覧を戻す
    ここまで
    (枚数 - 1)と移動元と経由と移動先と移動一覧でハノイ移動記録
    移動一覧に[移動元, 移動先]を配列追加
    (枚数 - 1)と経由と移動先と移動元と移動一覧でハノイ移動記録
    移動一覧を戻す
ここまで

●(枚数と移動元と移動先と経由で)ハノイ解法
    移動一覧 = []
    枚数と移動元と移動先と経由と移動一覧でハノイ移動記録
    移動一覧を戻す
ここまで

    枚数 = 1 が基底条件です。それより大きい場合、2 回の再帰呼び出しの間に最大の円盤を移動します。移動回数は T(n) = 2T(n - 1) + 1 となるため、時間計算量は O(2ⁿ) です。返却する手順に 2ⁿ - 1 件の移動を保存するため、出力に必要な空間計算量も O(2ⁿ) です。

    5.4 複数回再帰と反復化¶

    1 回の呼び出しから複数の再帰呼び出しを行う関数を題材に、呼び出し順序と反復化を確認します。複数回再帰(4) は、再帰呼び出しの間に数値を結果へ追加します。

    Red: 呼び出し順序を確認する¶

    再帰結果 = 4で複数回再帰
「複数回再帰: 呼び出し順序」と(再帰結果を「,」で配列結合)と「1,2,3,1,4,1,2」で検証

    Green: 2 つの再帰呼び出しを記述する¶

    ●(数で)複数回再帰
    結果 = []
    数と結果で複数回再帰処理
    結果を戻す
ここまで

●(数と結果で)複数回再帰処理
    もし、数 > 0ならば
        (数 - 1)と結果で複数回再帰処理
        結果に数を配列追加
        (数 - 2)と結果で複数回再帰処理
    ここまで
    結果を戻す
ここまで

    n > 0 のとき、n - 1 の処理、n の追加、n - 2 の処理の順に進みます。結果配列は参照型なので、各再帰呼び出しは同じ配列を更新します。

    末尾側の再帰をループへ置き換える¶

    2 回目の再帰呼び出しは、数値を 2 ずつ減らしていく末尾側の処理です。最初の再帰呼び出しを残したまま、この部分をループにできます。

    ●(数で)複数回再帰部分反復
    結果 = []
    数と結果で複数回再帰部分反復処理
    結果を戻す
ここまで

●(数と結果で)複数回再帰部分反復処理
    現在 = 数
    現在 > 0の間
        (現在 - 1)と結果で複数回再帰処理

「反復階乗: 0」と(0で反復階乗)と1で検証
「反復階乗: 5」と(5で反復階乗)と120で検証
    方法 時間計算量 追加の空間 特徴
    再帰階乗 O(n) O(n) 数式に近い形で表せますが、呼び出しごとの状態を保持します
    反復階乗 O(n) O(1) ループで状態を更新し、再帰呼び出しを使いません
    複数回再帰を明示スタック化 O(φⁿ) O(n) 呼び出し状態を配列スタックで管理します

    再帰の時間計算量は T(n) = T(n - 1) + T(n - 2) + O(1) となるため、O(φⁿ)（φ は黄金比）です。明示スタック版は再帰と同じ順序で呼び出しフレームを処理するため、時間計算量は変わりませんが、呼び出し状態はヒープ上の配列で管理され、最大の深さに比例する O(n) の追加領域を使います。

    再帰は問題を同じ形の小さな問題に分けられるときに、構造を簡潔に表現できます。一方、再帰の深さが大きい場合や、単純な繰り返しで表せる場合は、反復のほうが呼び出しスタックを消費しません。複数回再帰では、単純なループへの置き換えだけでなく、呼び出し順序を保つ明示スタックが必要になる場合があります。

    まとめ¶

    再帰関数は、問題を小さくする再帰ステップと、呼び出しを止める基底条件で構成されます。階乗と最大公約数は問題を縮小し、ハノイの塔と複数回再帰は複数の呼び出しを組み合わせます。反復化では、末尾側の処理をループに置き換えたり、明示的なスタックで呼び出し状態を管理したりします。8 王妃問題と迷路探索では、バックトラッキングによって矛盾する候補を早く除外します。

    アルゴリズム 計算量 特徴
    階乗 O(n) 線形再帰
    最大公約数 O(log min(x, y)) 余りを使って対数的に縮小
    ハノイの塔 O(2ⁿ) 移動手順数が指数的に増加
    8 王妃問題 O(n!)（行制約のみの候補数） 行・対角線の制約で枝刈り
    迷路探索 O(行数 × 列数) 訪問済みを記録する深さ優先探索

    次章では、データを特定の順序に並べ替えるソートアルゴリズムを学びます。
