## 技術メモ

### Java 版の特徴

| 概念 | Python | Java |
|------|--------|------|
| スワップ | `a[i], a[j] = a[j], a[i]` | `int tmp = a[i]; a[i] = a[j]; a[j] = tmp;` |
| ジェネリクス | `list[Any]` | `List<T>` |
| 例外クラス | 内部クラス | カスタム例外クラス |
| リスト操作 | リスト内包表記 | Stream API |

### テスト環境

- **フレームワーク**: JUnit 5
- **ビルドツール**: Gradle（または Maven）
- **Java バージョン**: 21（LTS）
