# アルゴリズムから始める なでしこ3 入門

テスト駆動開発から始めるなでしこ3入門の続編です。前作で学んだ Red → Green → Refactor を使い、アルゴリズムとデータ構造を段階的に実装します。

なでしこ3 の日本語の語順と助詞による関数呼び出しを活かしながら、Python 版と同じ題材を学びます。配列や辞書の表現、命令の構文は `gonako` 3.8.8 で実行して確認します。

## 対象読者

- なでしこ3 の変数、関数、条件分岐、繰り返しの基本を理解している方
- TDD の Red → Green → Refactor を一度以上実践した方
- アルゴリズムをテストで確かめながら学びたい方

TDD の基本や `gonako` の導入、テスト実行環境については、[テスト駆動開発から始める なでしこ3 入門](https://github.com/k2works/getting-started-tdd/tree/main/docs/article/nadesiko)を先に参照してください。

## 実装とテスト

記事中のテストは `ASSERT等` を使い、実装より先に期待する振る舞いを書きます。コード例は `gonako` で実行し、記事と実装の内容を同期させます。なでしこ3 の開発環境は `gonako` 3.8.8 を基準に整備します。
