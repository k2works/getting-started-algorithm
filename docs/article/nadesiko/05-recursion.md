# 第 5 章 再帰アルゴリズム

## はじめに

再帰とは、関数が自分自身を呼び出して問題を解く方法です。大きな問題を同じ形の小さな問題に分け、答えがすぐに求まるところまで進んでから、呼び出し元へ結果を返します。

再帰関数には、呼び出しを止める **基底条件** と、問題を小さくして再び関数を呼び出す **再帰ステップ** が必要です。基底条件がなかったり、再帰ステップで問題が小さくならなかったりすると、処理が終わりません。この章では、階乗、ユークリッドの互除法、ハノイの塔を実装し、再帰と反復を比較します。

## 5.1 階乗

非負整数 `n` の階乗は、`n` から 1 までの整数を掛け合わせた値です。`0!` は 1 と定義され、`n! = n × (n - 1)!` の関係を使うと再帰で表せます。この関数は非負整数を入力とする前提です。

### Red: 基底条件と再帰結果をテストする

```nako3
「階乗: 0の基底条件」と(0で階乗)と1で検証
「階乗: 1」と(1で階乗)と1で検証
「階乗: 5」と(5で階乗)と120で検証
```

### Green: 問題を 1 つ小さくする

```nako3
●(数で)階乗
    もし、数 <= 1ならば
        1を戻す
    ここまで
    (数 × ((数 - 1)で階乗))を戻す
ここまで
```

`階乗(5)` は `5 × 階乗(4)` を求め、さらに `4 × 階乗(3)` と続きます。`階乗(0)` に到達すると基底条件の 1 を返し、呼び出し元で順に乗算されます。

```
階乗(5)
= 5 × 階乗(4)
= 5 × 4 × 階乗(3)
= 5 × 4 × 3 × 階乗(2)
= 5 × 4 × 3 × 2 × 階乗(1)
= 5 × 4 × 3 × 2 × 1
= 120
```

`n` 回程度の関数呼び出しを行うため、時間計算量は O(n)、再帰呼び出しを保持する空間計算量も O(n) です。`n` が大きすぎると、処理系の再帰上限や利用可能なスタック容量に達する場合があります。

## 5.2 最大公約数 — ユークリッドの互除法

ユークリッドの互除法は、2 つの非負整数 `x`、`y` の最大公約数について、`gcd(x, y) = gcd(y, x % y)` が成り立つことを利用します。余りが 0 になったときの `x` が最大公約数です。

### Red: 基底条件と余りをテストする

```nako3
「最大公約数: 互除法」と(22と8で最大公約数)と2で検証
「最大公約数: 互いに素」と(7と11で最大公約数)と1で検証
「最大公約数: 余りが0」と(18と6で最大公約数)と6で検証
```

### Green: 余りを次の問題にする

```nako3
●(XとYで)最大公約数
    もし、Y = 0ならば
        Xを戻す
    ここまで
    (Yと(X % Y)で最大公約数)を戻す
ここまで
```

例えば `最大公約数(22, 8)` は、`最大公約数(8, 6)`、`最大公約数(6, 2)`、`最大公約数(2, 0)` と問題が小さくなり、2 を返します。余りは必ず小さくなるので、`Y = 0` の基底条件に到達します。

ユークリッドの互除法の時間計算量は O(log min(x, y)) です。再帰呼び出しの空間計算量も O(log min(x, y)) になります。引数は非負整数を前提とします。

## 5.3 ハノイの塔

ハノイの塔では、大小の異なる円盤を 3 本の柱の間で移動します。大きな円盤を小さな円盤の上に置かず、1 回に 1 枚だけ動かします。`n` 枚を移動元から移動先へ移すには、次の 3 段階に分けます。

1. 上の `n - 1` 枚を移動元から経由先へ移す。
2. 残った一番大きな円盤を移動元から移動先へ移す。
3. `n - 1` 枚を経由先から移動先へ移す。

### Red: 移動手順と基底条件をテストする

移動手順は `[移動元, 移動先]` の配列の一覧として返します。1 枚なら移動は 1 回、3 枚なら `2³ - 1 = 7` 回です。0 枚なら移動はありません。

```nako3
移動一覧 = 1と「A」と「C」と「B」でハノイ解法
「ハノイ: 1枚の移動数」と(移動一覧の配列要素数)と1で検証
移動 = 移動一覧の0を配列参照
「ハノイ: 1枚の移動元」と(移動の0を配列参照)と「A」で検証
「ハノイ: 1枚の移動先」と(移動の1を配列参照)と「C」で検証

移動一覧 = 3と「A」と「C」と「B」でハノイ解法
「ハノイ: 3枚の移動数」と(移動一覧の配列要素数)と7で検証
移動 = 移動一覧の0を配列参照
「ハノイ: 最初の移動」と(移動を「-」で配列結合)と「A-C」で検証
移動 = 移動一覧の3を配列参照
「ハノイ: 最大円盤の移動」と(移動を「-」で配列結合)と「A-C」で検証

移動一覧 = 0と「A」と「C」と「B」でハノイ解法
「ハノイ: 0枚なら移動しない」と(移動一覧の配列要素数)と0で検証
```

### Green: 移動手順を配列に記録する

再帰の途中で作った移動手順をひとつの配列に集めるため、配列を再帰関数に渡します。なでしこ3 の配列は参照型なので、各呼び出しが同じ配列に移動を追加します。

```nako3
●(枚数と移動元と移動先と経由と移動一覧で)ハノイ移動記録
    もし、枚数 <= 0ならば
        移動一覧を戻す
    ここまで
    もし、枚数 = 1ならば
        移動一覧に[移動元, 移動先]を配列追加
        移動一覧を戻す
    ここまで
    (枚数 - 1)と移動元と経由と移動先と移動一覧でハノイ移動記録
    移動一覧に[移動元, 移動先]を配列追加
    (枚数 - 1)と経由と移動先と移動元と移動一覧でハノイ移動記録
    移動一覧を戻す
ここまで

●(枚数と移動元と移動先と経由で)ハノイ解法
    移動一覧 = []
    枚数と移動元と移動先と経由と移動一覧でハノイ移動記録
    移動一覧を戻す
ここまで
```

`枚数 = 1` が基底条件です。それより大きい場合、2 回の再帰呼び出しの間に最大の円盤を移動します。移動回数は `T(n) = 2T(n - 1) + 1` となるため、時間計算量は O(2ⁿ) です。返却する手順に `2ⁿ - 1` 件の移動を保存するため、出力に必要な空間計算量も O(2ⁿ) です。

## 5.4 再帰と反復を比較する

階乗は再帰だけでなく、繰り返しでも実装できます。結果を 1 から順に更新し、呼び出しスタックを使わずに計算します。

```nako3
●(数で)反復階乗
    結果 = 1
    Iを1から数まで繰り返す
        結果 = 結果 × I
    ここまで
    結果を戻す
ここまで
```

```nako3
「反復階乗: 0」と(0で反復階乗)と1で検証
「反復階乗: 5」と(5で反復階乗)と120で検証
```

| 方法 | 時間計算量 | 追加の空間 | 特徴 |
|------|-----------|-----------|------|
| 再帰階乗 | O(n) | O(n) | 数式に近い形で表せるが、呼び出しごとの状態を保持する |
| 反復階乗 | O(n) | O(1) | ループで状態を更新し、再帰呼び出しを使わない |

再帰は問題を同じ形の小さな問題に分けられるときに、構造を簡潔に表現できます。一方、再帰の深さが大きい場合や、単純な繰り返しで表せる場合は、反復のほうが呼び出しスタックを消費しません。再帰を反復に変換する場合は、再帰呼び出しごとに保持していた状態をループ変数や明示的なスタックで管理します。

## まとめ

再帰関数は、問題を小さくする再帰ステップと、呼び出しを止める基底条件で構成されます。階乗と最大公約数は再帰的に問題を縮小し、ハノイの塔は 2 つの再帰呼び出しを使って移動手順を組み立てます。再帰と反復は計算量だけでなく、呼び出しスタックと問題の表現しやすさを基準に選びます。
