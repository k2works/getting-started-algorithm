## Python 版との違い

| 概念 | Python | Go |
|------|--------|----|
| 型宣言 | 型ヒント（任意） | 静的型付き（コンパイル時検査） |
| テスト | `pytest` | 標準 `testing` パッケージ |
| クラス | `class Foo:` | `struct` + メソッド |
| 例外 | `raise Exception` | 複数戻り値 `(T, error)` |
| リスト | `list` | スライス `[]T` |
| 辞書 | `dict` | マップ `map[K]V` |
| None | `None` | `nil` |
| 継承 | クラス継承 | インターフェース合成 |
| ガベージコレクション | 参照カウント + GC | トレーシング GC |
| パッケージ | モジュール | パッケージ（章ごとに分割） |
